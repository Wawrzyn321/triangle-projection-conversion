# UI Design — Triangle Projection Viewer

**Date:** 2026-05-05  
**Scope:** Visual polish, improved progress UI, disabled-state fixes. No new features.

---

## Layout

Side-by-side panels: 3D WebGL viewer on the left, 2D output canvas on the right. Both `600×450`. Flex row with a gap. Controls bar spans full width below both panels.

```
┌──────────────┬──────────────┐
│  3D viewer   │  2D output   │
│   (WebGL)    │  (canvas)    │
└──────────────┴──────────────┘
│          controls bar        │
└──────────────────────────────┘
```

## Theme

Dark. Background `#111827`, panel background `#1f2937`, borders `#374151`, primary accent `#3b82f6`, muted text `#9ca3af`.

## Controls Bar

Single horizontal bar below both panels. Left-to-right:

1. **Load model** — `<label>` wrapping a hidden `<input type="file">`, styled as a button. Always enabled.
2. Vertical divider.
3. **Triangles** button — runs algo on hardcoded triangles. Always enabled. Primary blue style.
4. **Model** button — runs algo on loaded model. **Disabled** (opacity + `cursor:not-allowed`) when no model is loaded. Enabled once a file is loaded.
5. Vertical divider.
6. **View presets** — "View" label + one button per `CameraAnimator.PRESETS` key (`front`, `back`, `top`, `bottom`, `left`, `right`). Muted secondary style.
7. **Spacer** (flex: 1).
8. **Progress badge** — right-aligned, visible only while algo is running. Hidden when idle.

## Progress Badge

Compact pill: pulsing blue dot + monospace text `"12/48 tris · 34.5%"`. Dark background `#0f172a`, blue border `#1e3a5f`. Replaces the raw `{message}` string. Hidden when not running.

## State Changes in App.tsx

Two new state variables:

- `modelLoaded: boolean` — set `true` in `loadModel()` after file loads. Drives `disabled` prop on Model button.
- `isRunning: boolean` — set `true` at start of `execute()`, `false` on completion. Drives progress badge visibility and disables both execute buttons while running (prevents double-submit).

## Styling

Single `App.module.css` file. No new dependencies. CSS modules imported into `App.tsx`. `CameraPresets.tsx` receives a `buttonClassName` prop so it can apply the shared preset button style.

## Files Changed

| File | Change |
|------|--------|
| `src/App.tsx` | Add `modelLoaded` + `isRunning` state; apply CSS module classes; restructure JSX for new layout |
| `src/App.module.css` | New file — all styles |
| `src/CameraPresets.tsx` | Accept `buttonClassName` prop |
| `src/index.css` | Add `box-sizing: border-box` reset, `height: 100%` on html/body |

## Out of Scope

- No changes to algorithm (`algo.ts`) or geometric utilities
- No mobile/responsive layout
- No theming toggle (dark only)
- No changes to Three.js scene colors
